# Роутер OpenWrt — простой гайд для всех

Роутер: **Tenda BE12 Pro**, прошивка OpenWrt. Он раздаёт интернет, обходит блокировки для всей сети (YouTube, Discord, Instagram и др.), режет рекламу и держит Telegram-прокси. Этот гайд — как пользоваться и что делать, если что-то сломалось.

---

## 1. Как зайти

| Способ | Куда | Логин / пароль |
|---|---|---|
| Веб-интерфейс (LuCI) | http://<ROUTER_IP> | user / <ROUTER_PASSWORD> |
| Командная строка (SSH) | `ssh user@<ROUTER_IP>` | user / <ROUTER_PASSWORD> |

Wi-Fi: сети `OpenWrt_2` (2.4 ГГц) и `OpenWrt_5` (5 ГГц). Пароль от Wi-Fi меняется в LuCI: **Network → Wireless → Edit → Wireless Security**.

## 2. Что на роутере работает (и не надо трогать)

- **zapret2** — обход блокировок. Стартует сам при включении роутера.
- **Блокировщик рекламы** (внутри Zapret-Manager) — режет рекламу и вредоносные сайты на всех устройствах.
- **Telegram WS-прокси** — для телеграм-клиентов, которые его используют.
- **Честный DNS** (DoH через Cloudflare) — провайдер не может подменить адреса сайтов.
- **SQM** — пинг не скачет, когда кто-то качает на полной скорости.

## 3. Частые задачи

### «YouTube / Discord / Instagram перестал открываться»

1. Подожди 5 минут — провайдеры иногда мутят временно.
2. Перезапусти zapret2:
   ```
   ssh user@<ROUTER_IP>
   /etc/init.d/zapret2 restart
   ```
3. Если не помогло — перезагрузи роутер (LuCI: System → Reboot, или выключи/включи питание).
4. Если снова не помогло — напиши инженеру (тому, кто настраивал). Пригодится файл со статистикой:
   ```
   ssh user@<ROUTER_IP> 'tail -20 /tmp/zhealth.log'
   ```

### «Игра выкидывает / не подключается к матчу»

Обход может мешать игровому UDP. Включи-выключи «игровой режим»:

```
ssh user@<ROUTER_IP> '/opt/zapret2/game-udp.sh off'   # выключить (стандарт)
ssh user@<ROUTER_IP> '/opt/zapret2/game-udp.sh on'    # включить обратно
```

Стандартное состояние — **off**. Если игра работает нормально — ничего не трогай.

### «Хочу узнать, жив ли обход вообще»

```
ssh user@<ROUTER_IP> '/opt/zapret2/healthcheck.sh && tail -1 /tmp/zhealth.log'
```

Если видишь строку вида `www.youtube.com:200 discord.com:200 ...` — всё работает (200/301/302 = хорошо, 000 = плохо).

### «Пропал интернет полностью»

1. Проверь, что роутер включён и горят индикаторы.
2. Перезагрузи роутер.
3. Если после перезагрузки интернета нет — позвони провайдеру или проверь кабель. Обход блокировок тут ни при чём: он не умеет ронять интернет целиком.

## 4. Правила безопасности (чего НЕ делать)

- **Не нажимай «Reset»** на роутере — слетит вся настройка.
- **Не обновляй прошивку** (System → Backup/Flash) самостоятельно — это SNAPSHOT-версия, обновление только с бэкапом и инженером.
- **Не выключай в LuCI разделы zapret2**, если не знаешь зачем.
- Не меняй настройки Network → Interfaces — можно потерять интернет.

## 5. Бэкап — где лежит

Полная резервная копия настроек: на компьютере в `C:\fZapret2\openwrt\backup\20261115\`. Если роутер сгорит — из неё всё восстановится на новом.

## 6. Бонусные возможности (можно попросить инженера включить)

- **Гостевой Wi-Fi** — отдельная сеть для гостей без доступа к твоим устройствам.
- **VPN-сервер (WireGuard)** — подключаться к домашней сети из любой точки мира.
- **Wake-on-LAN** — будить домашний компьютер удалённо.
- **USB/файловая шара** — если у роутера есть USB, можно сделать сетевой диск.
- **Расписание Wi-Fi** — глушить Wi-Fi ночью.
- **Статический IP для устройства** — чтобы у приставки/ПК адрес не менялся.
