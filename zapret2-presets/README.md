# zapret2-presets — конструктор стратегий zapret2 в LuCI

Страница внутри панели: «Службы → Zapret Manager → Zapret2 конструктор» для тех, кто не работает в shell:
сборка набора стратегий карточками, проверка одной кнопкой, пресеты.

## Что умеет

**Конструктор**
- Все стратегии из `/etc/config/zapret2` — карточками, сгруппированными по
  семействам (FZ, YouTube, Discord, Игры, DoH, V-серия, ALT, Circular).
- На карточке: протокол (TCP/UDP), порты, L7-фильтр, признак hostlist.
- Клик по карточке — вкл/выкл в рабочем наборе (жёлтая точка = есть
  неприменённые изменения). Поиск по имени.
- **Применить набор** — пишет `enabled` в UCI и перезапускает zapret2.
- **Сбросить** — вернуть рабочий набор к активному состоянию.
- **Проверить** — curl-пробы с роутера: YouTube, Google, googlevideo,
  Discord, GitHub, Telegram. Зелёный чип = сервис отвечает (HTTP-код и
  время), красный = недоступен. Проверка ничего не меняет в конфиге.
  Примечание: Telegram с самого роутера красный — это нормально, он идёт
  через sTGWS-прокси на клиентах, а не напрямую.

**Сравнение стратегий**
- Встроенный прогон strategy-check прямо на странице: выбор стратегий
  чекбоксами (по умолчанию отмечены стратегии рабочего набора), списки,
  протокол (TLS 1.3/1.2/HTTP, QUIC при наличии curl-h3), повторы, тайм-аут,
  лимит доменов, HEAD/GET.
- Живой статус: состояние, таблица очков (прошло/всего по стратегиям),
  хвост журнала, остановка прогона, восстановление службы при сбое.
- Кнопка «+ В набор» у каждой стратегии в результатах — добавляет её
  в рабочий набор конструктора (применение — кнопкой «Применить набор»).
- На время прогона основной zapret2 приостанавливается — об этом
  предупреждает диалог запуска.

**Автопроверка по расписанию (cron)**
- Статус: включено ли расписание, автоприменение, кулдаун, лимит, идёт ли
  проверка сейчас; журналы проверок и автоподбора.
- Управление: вкл/выкл расписание (ежечасно в :17), вкл/выкл
  автоприменение лучшей стратегии, кулдаун между автоприменениями (1–168 ч),
  лимит автоприменений подряд (0–20), кнопка «Проверить сейчас».

**Пресеты**
- Карточки пресетов: имя, описание, число стратегий, отметка «активен».
- **Применить** — включить стратегии пресета, выключить остальные,
  перезапуск zapret2.
- **Сохранить набор как пресет** — снимок рабочего набора из конструктора
  (можно сохранить ещё не применённый).
- **Удалить** пресет.

Блобы, lua-скрипты и листы не затрагиваются — только флаги `enabled`
у секций `strategy`.

## Формат пресета

Файл `/etc/zapret2-presets/<имя>.txt`:

```
# Описание (первая строка с # попадает в карточку)
fz68_googlevideo
fz97_general
```

Одна строка = имя секции strategy из `/etc/config/zapret2`.
Можно править вручную по SSH.

## Установка

```sh
sh install-zapret2-presets.sh --check   # диагностика без изменений
sh install-zapret2-presets.sh           # установка
sh install-zapret2-presets.sh --remove  # удаление страницы (пресеты остаются)
```

Установка почти полностью аддитивна: свой view
(`view/zapret-manager/presets.js`), ACL, `/etc/zapret2-presets/check.sh`.
Единственная правка чужого файла — один пункт меню в
`/usr/share/luci/menu.d/luci-app-zapret-manager.json`: вставка по структуре
конца файла, с бэкапом в `/opt/zapret-manager-luci/backups/presets-menu-*`
и валидацией JSON (jsonfilter) до записи; при невалидном результате файл
не трогается. `--remove` восстанавливает меню из бэкапа.
Страница использует общий модуль стилей zapret-manager.common, поэтому
выглядит как остальные страницы панели.

## Штатные пресеты

- `hybrid-fz` — рабочая связка из нашей миграции (Ростелеком/ЕСК/МГСТ):
  fz-профили + Youtube_UDP, 15 стратегий. Страховка для отката.
- `all-off` — выключить все стратегии (диагностика «чистого» канала).

## Тонкая настройка

Параметры самих стратегий — в штатном приложении «Службы → Zapret2»
(порты, фильтры, листы, lua, blockcheck, сравнение стратегий). Конструктор —
слой быстрой сборки и переключения поверх него.
