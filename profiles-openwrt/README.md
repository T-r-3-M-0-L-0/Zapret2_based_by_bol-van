# Профили zapret2 для OpenWrt

Архив содержит 71 профиль: 34 ранее сохранённых на роутере (в том числе 8 включённых) и 37 перенесённых из сборки T-r-3-M-0-L-0. У всех профилей суффикс _openwrt; префикс friend_ удалён. Состояния включения сохранены. Роутер при создании архива не изменялся.

profiles/*.uci — отдельные профили в формате UCI вашего Zapret Manager.
etc/config/zapret2 — полная объединённая конфигурация с переименованными профилями.
dependencies/shared.uci — общие настройки и определения списков, blobs и Lua для отдельных профилей.
opt/zapret2/ — списки, файлы фейковых пакетов и Lua. Пути в конфигурации соответствуют установке /opt/zapret2. Импортированные данные расположены в /opt/zapret2/profiles-openwrt.
manifest.csv — перечень профилей и их состояние включения.
SHA256SUMS.txt — контрольные суммы файлов архива.

Отдельный .uci содержит секцию стратегии; для переноса на другую установку нужны также общие определения и связанные файлы. Обычный OpenWrt без вашего Zapret Manager не получает поддержку этих секций автоматически. Для восстановления всей конфигурации сначала сохраните свои настройки, затем разместите etc/config/zapret2 и содержимое opt/ по соответствующим абсолютным путям. Перезапускать службу следует после проверки UCI и nfqws2 --dry-run. Все альтернативы одновременно включать не нужно: действует первый подходящий профиль.

Сохранены исходные параметры стратегий. В старых профилях есть ссылки на отсутствующие в исходной установке blob_quic_initial_steamcommunity_com, blob_stun2, blob_tls_clienthello_www_onetrust_com и другие пользовательские blobs; этот архив переименовывает и сохраняет профили, но не исправляет такие исходные зависимости. Импортированные 37 профилей используют отдельные данные в profiles-openwrt/blobs.lua; недостающие в репозитории друга четыре бинарных файла были дополнены из Flowseal. В ipset-all.txt импортированной сборки только тестовый адрес 203.0.113.113/32.
